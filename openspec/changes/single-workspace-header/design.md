## Context

Electron 使用默认原生标题栏；React 还渲染品牌条和各页面 main-head。用户给出的 Codex 示例是窗口控制、标题与操作共用一行。

## Goals / Non-Goals

**Goals:** 一个紧凑的全窗口顶栏，所有页面复用，右侧可容纳持续增加的操作。

**Non-Goals:** 不重做导航、任务表格或详情面板，不改变执行及权限语义。

## Decisions

1. Electron macOS 使用 hiddenInset，保留原生红黄绿与系统窗口能力，React 预留左侧空间。其它桌面系统使用原生窗口控制覆盖，保留右侧安全空间。
2. WorkspaceHeader 为唯一应用级 header，集中侧栏开关、页面或会话标题、现有页面操作；移除品牌条及页面重复 header。单纯隐藏原生标题文字仍会留下额外一层，故不采用。
3. 现有会话头改为顶栏内容，面包屑改为同一行的定位图标与标题提示；标题优先缩短，按钮不换行，极窄时操作区可横向滚动并保持键盘可达。
4. 顶栏留白为 drag，按钮、菜单及标题交互区域为 no-drag；复用现有控件，不增加依赖或窗口权限。

## Risks / Trade-offs

- 原生控制遮挡 → 平台标识与左右安全区。
- 拖动区域吞掉点击 → 单独标记交互区域，真实桌面点击与拖动验证。
- 长标题挤掉按钮 → flex 最小宽度、文本省略、操作区不换行及窄窗口检查。

## Migration Plan

当前实际任务已获授权暂停且资源释放。先验证单层 header、页面动作及宽窄布局，随后连同任务权限更新包一次安装，重启后保持该任务暂停。
