## Purpose

提供可在当前项目目录直接使用的持续交互终端，让用户在多个独立 Shell 中工作并保留各自的命令、目录与输出；明确终端关闭和应用退出后的进程清理边界，避免标签存在但终端会话已丢失或产生残留进程。

## ADDED Requirements

### Requirement: 人工工具不参与 Agent 互斥
系统 SHALL 只在 Agent 之间限制同项目并发；人工终端、浏览器和文件工具不得占用 Agent 并发额度或与 Agent、其它终端互斥。

#### Scenario: Agent 与两个终端同时运行
- **WHEN** 项目中有 Agent 执行，用户创建两个终端
- **THEN** 两个终端均正常启动，Agent 不被暂停或停止，其它项目 Agent 的并发额度不受终端影响

### Requirement: 多个持续终端
系统 SHALL 为每个新终端创建独立交互 Shell，其初始工作目录来自创建时当前项目。系统 SHALL 保留终端内工作目录与 Shell 状态，标签切换不会重启 Shell。

#### Scenario: 两个终端独立目录
- **WHEN** 用户在同一项目新建两个终端，并在第一个终端执行 cd
- **THEN** 第一个终端保留新目录，第二个终端仍在自己的目录，两个终端输入输出互不混合

### Requirement: 输入输出与尺寸调整
系统 SHALL 支持交互输入、中文输出、控制键和终端窗口尺寸调整，输出必须归属于正确终端。

#### Scenario: 输入、打断和中文输出
- **WHEN** 用户在终端输入命令、输出中文并使用 Ctrl+C
- **THEN** 终端正确显示中文，Ctrl+C 传递给该终端的前台进程，不中断其它终端或 Agent

### Requirement: 明确生命周期与容量
系统 SHALL 在关闭终端标签时终止所属 Shell 并释放资源，应用退出时清理全部所属终端。达到容量限制时 SHALL 明确提示，不静默替换已有终端。

#### Scenario: 关闭其中一个终端
- **WHEN** 用户关闭两个终端中的一个
- **THEN** 只终止被关闭终端的进程，其它终端继续运行，关闭中的失败有可见提示

### Requirement: 无项目不误用目录
系统 SHALL 在未选择有效项目或目录不可访问时阻止终端启动并显示可操作提示，不回退到任意工作目录。

#### Scenario: 当前项目目录不存在
- **WHEN** 用户在目录不存在的项目中创建终端
- **THEN** 系统提示重新选择有效项目，且不创建其它目录中的 Shell
