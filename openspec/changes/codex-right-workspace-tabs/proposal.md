## Why

右侧目前以“工具类别”分组，浏览器里面再嵌套网页标签，文件与终端挤在一个面板。用户希望直接切换正在使用的网页、文件、终端和变更，交互与提供的 Codex 截图一致。

## What Changes

- 右侧统一一层可关闭标签，每个网页直接成为侧栏标签，取消浏览器内部标签条；标签条提供新建入口。
- 文件与终端拆开。文件工具单例，重复打开聚焦现有文件页并保留当前文件；左侧文件内容、右侧目录树，可筛选、展开和收起目录树。
- 终端为持续交互 Shell，每个新建终端独立状态，初始目录来自创建时当前项目，允许多个终端。
- 变更保持独立单例标签，任务详情继续保留。
- 切换工具保留页面、文件和终端状态，关闭终端清理所属进程，应用退出统一清理。
- 按用户明确选择：项目目录仅在 Agent 之间互斥；浏览器、文件和所有人工终端彼此及与 Agent 完全可并发，不占 Agent 并发额度。

## Capabilities

### New Capabilities
- `right-workspace-tabs`：统一标签生命周期、浏览器逐页标签、单例文件/变更与多终端。
- `interactive-workspace-terminal`：项目目录初始化、持续 PTY 输入输出、会话隔离及生命周期清理。

### Modified Capabilities

无；当前主 specs 目录无已发布能力文件，本变更在独立 delta 中描述。

## Impact

- React：RightDock、WorkspaceHeader、ChatSurface、BrowserPane、工作区文件/终端组件及样式、上下文状态。
- Electron：浏览器目标的显示/隐藏与事件同步，避免网页覆盖其它标签。
- Rust：基于已有 app-server `command/exec` PTY 能力提供终端启动、写入、尺寸调整、输出和结束；继续使用任务的工作目录和沙箱。
- 测试：标签去重/关闭/选择、文件树布局、异步隔离、多终端、进程清理、原生浏览器显示/隐藏与宽窄窗口。
