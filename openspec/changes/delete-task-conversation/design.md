## Context
现有会话下拉仅切换和新建；侧栏支持收起。任务软删除已有恢复窗口。用户已确认入口及人工会话范围。

## Goals / Non-Goals
支持清理误建人工会话和恢复历史，保留任务及结果。不物理删除数据，不删除主会话，不停止执行作为删除副作用。

## Decisions
- 采用现有下拉每行独立菜单和侧栏菜单；相比顶栏常驻垃圾桶，减少误触且能管理非当前会话；不将删除放到任务菜单。
- chat_conversations 新增 deleted_at；列表和普通会话读取过滤，恢复专用查询可读墓碑。独立模块负责事务删除与恢复；服务 actor 检查仍存活执行，仓储检查 active run、资源保留、版本和类型。
- 已删除窗口新增会话分组。关联任务已删除时提示先恢复任务；恢复保持原 closed 状态，不重新执行。
- 快照移除当前会话时，按任务最近访问的存活会话、更新时间回退；没有会话则显示该任务详情。清除旧 detail 请求显示权；会话草稿留在内存原键，恢复可继续编辑。

## Risks / Trade-offs
- 旧页面继续发送 → 普通读取拒绝墓碑；恢复递增版本，旧版本不能删除。
- 主会话与提取历史耦合 → 禁止主会话，保留结果外键和来源内容。
- 删除非当前会话导致导航跳动 → 只修复已消失的选中会话。

## Migration Plan
启动在既有迁移事务中幂等加列，旧数据默认未删除。本机保留旧应用备份、数据库和浏览器状态；旧应用不认识墓碑，回滚应用可能重新显示墓碑会话，不承诺旧版具有删除语义。
