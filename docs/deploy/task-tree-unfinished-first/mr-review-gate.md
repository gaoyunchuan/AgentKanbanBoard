## 需求与取舍

用户打开任务树是为了找未完成工作来推动。旧排序只有根置顶、position、ID，没有判断分支是否全部结束。新排序在每层同级分支中，把自身或后代存在未完成任务的分支放前面，其余分支放后面；completed 和 cancelled 都算结束。同组沿用原排序规则。
