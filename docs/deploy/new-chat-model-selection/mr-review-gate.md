## 需求与原因

新进入的会话需要在首条消息前调整模型和推理强度。旧模型弹窗仅允许有会话记录时保存，草稿未携带模型参数，无法在首次执行前设定。

模型配置现在属于当前草稿。选择并保存只更新草稿；首次发送先创建会话，再保存模型配置，成功后才发送。已有会话通过既有接口及版本检查保存，运行中仍禁止改模型。弹窗保存回调固定为打开时目标，避免轮询改变写入归属。

另修复两个相关边界：失败后将未编辑草稿移入已创建会话并清理旧键；等待期间有新输入时保留原文及新输入，目标未另选模型则补回待保存配置，重试不能按默认模型执行。任务树默认选择只在实际树页面补全，新聊天不会被2.5秒轮询选回首个任务。
