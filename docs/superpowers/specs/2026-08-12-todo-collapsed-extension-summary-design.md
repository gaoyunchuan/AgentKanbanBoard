# To Do 折叠态扩展信息摘要设计

## 背景

To Do 任务的“过程跟踪”和“结果复盘”目前只在展开详情后可见。任务收起后，主行第一列只保留标题，用户无法在列表中快速回顾已有过程和结论。

## 目标

当任务至少包含一条非空的过程跟踪或结果复盘记录时，在收起态的任务标题下展示一行摘要，使用户无需展开详情即可浏览两类扩展信息。

## 非目标

- 不修改任务数据模型、SQLite 表结构、Tauri command 或快照持久化链路。
- 不在摘要中提供新增、编辑或删除能力；扩展信息继续在展开详情中编辑。
- 不改变现有搜索、筛选、分页、树结构、关联 Thread、日期和状态交互。
- 不增加新的表格列，也不改变五列表格的隐藏顺序。

## 展示规则

1. 摘要仅在任务收起时显示；展开详情后隐藏，避免与完整内容重复。
2. 对每个字段按换行拆分，去除每条记录首尾空白并忽略空行，但不修改持久化的原始字符串。
3. 字段顺序固定为“过程跟踪”在前、“结果复盘”在后。
4. 同一字段的多条记录使用 ` · ` 连接；两个非空字段使用 ` ｜ ` 连接。
5. 完整格式为 `过程跟踪：记录1 · 记录2 ｜ 结果复盘：复盘1 · 复盘2`。
6. 只有一个字段非空时，只展示该字段及其标签，不保留空字段或多余分隔符。
7. 两个字段均为空或只包含空白字符时，不渲染摘要，任务保持现有紧凑行高。
8. 摘要在视觉上固定为一行，超出任务列可用宽度时以省略号截断，不换行且不产生横向滚动。
9. 摘要使用较标题更弱的文字层级；字段标签可区分内容，但不能抢占标题的视觉优先级。

## Markdown 命名链接

- 摘要沿用现有 Markdown 兼容展示语义：`[名称](http://...)` 和 `[名称](https://...)` 显示为可点击的短名称。
- 点击命名链接继续委托现有 `openExternalLink` 链路处理。
- 非 HTTP(S) 或不符合现有命名链接语法的内容按普通文本显示，不能引入 HTML 注入或放宽协议白名单。

## 组件与布局

- 在 `TodoListView` 的任务第一列内部，将标题输入框与摘要放入一个可收缩的纵向内容容器。
- 新增职责单一的折叠摘要组件：接收任务、展开状态和打开链接回调，负责非空行解析、字段拼接及安全 Markdown 展示。
- 拖拽、展开、置顶和状态控件继续与标题首行对齐；摘要从标题文字起始位置向下排列。
- 摘要必须嵌套在第一列中，不能成为 `.todo-grid` 的新直接子元素，确保五个网格轨道及 `nth-child()` 尾列隐藏规则不变。
- 根任务、子任务、置顶任务、已完成任务和已取消任务使用同一摘要规则；现有缩进、背景和标题删除线语义不变。

## 状态与数据流

摘要直接从当前 React 任务状态中的 `processTracking` 和 `resultReview` 派生，不维护副本，也不触发额外加载或保存。

编辑流程仍为：

`ExtensionSection → updateTask → applyTasks → saveSnapshot`

用户在展开详情中完成编辑后，收起任务时摘要立即反映当前状态；保存失败的既有反馈和回滚语义保持不变。

## 异常与边界

- 空标题任务使用现有“未命名任务”可访问名称，不影响摘要内容。
- 超长文本、超长链接名称和窄窗口统一由单行截断处理。
- 摘要中的链接点击不得触发任务展开、标题编辑或其他行操作。
- 摘要不参与键盘焦点恢复、标题快捷键或拖放排序逻辑。

## 验收标准

- 同时存在过程跟踪和结果复盘时，收起态按固定顺序在标题下显示一行完整摘要语义。
- 同一字段的所有非空记录按原顺序使用 ` · ` 拼接；字段间使用 ` ｜ ` 拼接。
- 仅一个字段有内容时不显示另一个字段及多余分隔符。
- 空字符串、纯空白和空行不会生成空摘要。
- 展开后折叠摘要消失，完整详情仍显示并可编辑；再次收起后摘要恢复且反映最新内容。
- HTTP(S) 命名链接显示短名称并可安全打开，危险协议不成为可点击链接。
- 摘要始终为一行，溢出显示省略号；表头与五列任务行继续对齐，页面不产生横向滚动。
- 无扩展信息的任务保持现有紧凑布局，树缩进、置顶、完成态和关联 Thread 展示不回归。

## 验证方案

- 组件测试覆盖双字段、单字段、空白值、多条记录顺序与分隔符。
- 组件测试覆盖展开隐藏、编辑后收起即时更新以及再次展开。
- 集成测试覆盖 HTTP(S) 命名链接的显示与点击，并确认危险协议为普通文本。
- DOM 回归确认 `.todo-grid` 仍有五个直接子元素，摘要位于第一列标题下。
- 运行 To Do List 与 Markdown 链接相关测试，再运行完整前端测试和生产构建。
- 在普通浏览器预览中检查 `1440 × 1024` 与 `1024 × 768`，确认摘要单行截断、列对齐、无横向溢出且控制台无 Tauri bridge 错误。
