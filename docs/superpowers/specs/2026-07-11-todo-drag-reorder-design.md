# To Do 任务拖放排序设计

## 目标

任务拖放同时支持同级排序与变为子任务，不再把所有落点都解释为“成为目标任务的子任务”。

## 交互规则

- 目标任务行上方 25%：插入到目标任务之前，显示顶部蓝色横线。
- 目标任务行中间 50%：成为目标任务最后一个子任务，整行显示浅蓝高亮。
- 目标任务行下方 25%：插入到目标任务之后，显示底部蓝色横线。
- “之前/之后”沿用目标任务的 `parentId`，因此得到同级排序；拖动任务连同其全部后代一起移动。
- 禁止把任务移动到自身或自身后代中，非法落点不改变数据。
- 拖动结束或离开有效目标后清除视觉提示。

## 数据与验证

- 新增纯函数处理相对目标的 `before`、`inside`、`after` 三种移动，不改变任务状态及扩展字段。
- 继续以 `parentId + position` 表达树结构，并在移动后统一归一化同级位置。
- 单元测试覆盖向上排序、向下排序、跨层级排序、成为子任务和循环保护；组件测试覆盖三种落点映射与提示清理。
