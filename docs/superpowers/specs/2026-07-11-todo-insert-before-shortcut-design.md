# Todo List 向上新建快捷键设计

## 目标

在 Todo List 的任务标题输入框中新增 `Cmd+Shift+Enter` 快捷键，在当前任务正上方创建一个同级空任务并自动聚焦。现有 `Cmd+Enter` 在当前任务正下方创建同级任务的行为保持不变。

## 交互行为

- `Cmd+Enter`：在当前任务之后插入同级任务。
- `Cmd+Shift+Enter`：在当前任务之前插入同级任务。
- 新任务继承当前任务的 `parentId`，不改变当前任务及其父子任务关系。
- 创建后自动聚焦新任务标题，并按现有快照保存流程持久化。
- 页面快捷键提示同时展示向上和向后新建能力。

## 实现设计

扩展现有 `insertSiblingTask` 树操作，使其接受 `before` 或 `after` 插入方向，并继续统一负责同级任务的位置调整与归一化。标题输入框的键盘事件根据 `Shift` 状态选择方向，继续复用现有的新任务创建、分页定位、聚焦和持久化流程。

不新增独立状态，不改动拖放、缩进、提升层级及后端数据结构。

## 测试与验收

- 树操作测试验证 `before` 会将新任务插入当前任务正前方，且保持同级。
- 保留并覆盖 `after` 的既有顺序，防止 `Cmd+Enter` 行为回归。
- 组件测试验证 `Cmd+Shift+Enter` 创建上方同级任务并聚焦新任务。
- 组件测试验证快捷键提示包含两种新建方式。
- 运行前端测试、构建和 `git diff --check` 作为完成证据。
