# To Do List 周视图设计

## 目标

在 To Do List 工具栏增加“周视图”切换按钮。启用后，仅展示过去滚动 168 小时内实际发生变动的任务，同时保留命中子任务的完整祖先路径。

`updated_at` 只作为内部筛选依据，不在列表、详情、提示或其他用户界面中展示。

## 时间与变动口径

- 时间窗口为当前时刻向前滚动 168 小时，不按自然周切分。
- 边界使用包含语义：`updated_at >= 当前时刻 - 168 小时`。
- 新建任务的 `created_at` 与 `updated_at` 相同，因此视为刚发生变动。
- 标题、状态、日期、父子层级、同级顺序、置顶状态、过程跟踪或结果复盘任一持久化字段实际变化时，更新该任务的 `updated_at`。
- 完整快照中内容未发生变化的任务不得刷新 `updated_at`。
- 无法解析或缺失 `updated_at` 的任务不直接命中周视图；如果它是命中任务的祖先，仍为保留层级路径而展示。

## 交互设计

- 在现有状态筛选控件旁增加“周视图”按钮，不增加新的表格列。
- 按钮使用可辨识的启用态，并通过 `aria-pressed` 暴露切换状态。
- 周视图与搜索、状态筛选按 AND 组合。
- 启用或关闭周视图时回到第一页；搜索或状态筛选变化时继续沿用现有回到第一页的行为。
- 如果子任务命中过去 168 小时窗口，展示其全部祖先；不额外展示未命中的兄弟任务或后代任务。
- 从 Thread 反向定位 Task 时，沿用现有“清空筛选后定位”的规则，同时关闭周视图，确保目标任务可见。
- 空状态沿用现有“没有匹配的任务”，不展示内部更新时间。

## 数据流与实现边界

### 后端更新时间语义

`save_todo_tasks` 继续接收完整任务快照，并继续负责插入、更新和删除。SQLite upsert 增加字段差异判断：只有持久化字段实际变化时才执行更新并写入新的 `updated_at`。新任务仍使用后端时钟同时生成 `created_at` 与 `updated_at`。

这项修正是周视图准确性的前置条件。当前实现会在任一快照保存时刷新所有任务，直接使用现状会把未变动任务误判为最近变动。

### 前端内部模型

`TodoTask` 增加仅供内部使用的可选 `updatedAt`，`mapBackendTodoTask` 从 `updated_at` 映射该字段；保存输入不回传或允许前端覆盖后端时间戳。

任务在当前会话中发生实际变化时，前端为受影响任务写入本地即时更新时间，确保周视图能立即反映刚完成的编辑。重新加载后以后端持久化时间为准。层级归一化或排序导致其他任务的持久化字段变化时，这些任务也属于实际变动。

周视图启用时立即采集当前时间，此后每 60 秒刷新一次时间基准，使滚动窗口能随时间推进；时间字段不渲染到界面。浏览器 demo 数据提供近期与过期样例，以便直接验收按钮状态和筛选结果。

### 树筛选

现有搜索和状态筛选已经通过任务 id 集合保留命中任务的祖先。周视图加入同一匹配条件，再复用祖先补全流程，避免形成另一套树展示规则。完成度派生排序、置顶排序和每页 200 条分页均保持不变，只作用于筛选后的可见任务。

## 错误与兼容处理

- 无效时间字符串按未命中处理，不阻断整个列表渲染。
- 不迁移或猜测历史真实变动时间。旧版本曾全量刷新 `updated_at`，这些历史误差无法可靠还原；发布后的最初 168 小时内可能出现旧的误命中，之后会自然退出窗口。
- 不新增数据库字段或迁移，不改变 `updated_at` 的后端所有权。
- 不改变 Thread/Task 关联加载、五秒 BoardData 轮询或 To Do 完整快照边界。

## 验收标准

1. 工具栏显示“周视图”按钮，启用状态清晰且具备 `aria-pressed`，界面任何位置都不显示更新时间。
2. 启用后只直接命中 `updated_at` 位于当前时刻前 168 小时内（含边界）的任务。
3. 命中子任务时显示完整祖先路径，不显示未命中的兄弟和后代。
4. 周视图可与搜索、状态筛选组合，并在切换时回到第一页。
5. 跨视图定位 Task 会关闭周视图并成功定位目标。
6. 新建或编辑任务后，启用中的周视图立即显示受影响任务。
7. 保存完整快照时，未变化任务的 `updated_at` 保持不变，实际变化任务的 `updated_at` 更新，新建任务同时获得创建与更新时间。
8. To Do 既有树编辑、完成度与置顶排序、分页、关联 Thread 和响应式列布局行为不回归。

## 测试与验证

- 前端组件测试覆盖按钮切换、168 小时边界、过期任务、无效时间、搜索与状态组合、祖先补全、兄弟排除、分页复位、导航清除和当前会话编辑后立即命中。
- 映射测试覆盖 `updated_at -> updatedAt`，并确认保存输入不包含客户端更新时间。
- Rust 仓储测试覆盖未变化快照不刷新时间、单个任务变化只刷新该任务、排序或层级变化刷新受影响任务，以及新建任务的时间初始化。
- 运行 To Do 相关前端测试、完整前端测试与构建、Rust 测试、Rust 格式检查和 `git diff --check`。
- 在 1440 × 1024 和 1024 × 768 验证按钮布局、启用态、筛选结果、无横向溢出和控制台零错误。
