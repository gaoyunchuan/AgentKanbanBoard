# To Do 空任务删除后的光标位置设计

## 目标

修复 To Do List 中空标题任务按 `Backspace` 删除后，上一任务标题被全文选中的问题。删除完成后，上一任务标题输入框应获得焦点，光标折叠在文字末尾。

## 范围

- 仅修改空标题任务按 `Backspace` 删除时的聚焦行为。
- 状态菜单中的“删除任务”保持现状。
- 新建任务、缩进和提升层级等已有聚焦场景继续沿用全文选中行为。
- 任务树删除、快照持久化和完成度派生排序逻辑不变。

## 方案

为现有待聚焦状态补充聚焦模式：

- `select`：聚焦后全文选中，作为默认模式，保留现有行为。
- `end`：聚焦后把选区起点和终点都设置为标题长度，使光标位于文字末尾。

空标题任务处理 `Backspace` 时，继续按当前完成度派生顺序寻找上一条可见任务，但提交任务快照时将聚焦模式指定为 `end`。统一聚焦副作用根据模式执行 `select()` 或 `setSelectionRange()`，完成后清理待聚焦状态。

## 边界行为

- 当前空任务不是第一条时，聚焦派生展示顺序中的上一任务。
- 当前空任务是第一条但列表仍有其他任务时，沿用现有目标计算，聚焦删除后留下的第一条任务，并把光标置于末尾。
- 列表仅有一条任务时不触发删除，与现有行为一致。
- 上一任务标题为空时，文字末尾即位置 `0`。

## 验证

在 `TodoListView` 组件测试中新增回归用例：

1. 准备一个有标题任务和其后的空标题任务。
2. 聚焦空标题任务并按 `Backspace`。
3. 验证空任务已删除、上一任务获得焦点。
4. 验证上一任务的 `selectionStart` 和 `selectionEnd` 都等于标题长度。
5. 再按一次 `Backspace`，验证只删除标题末尾一个字符，而不是清空整个标题。
