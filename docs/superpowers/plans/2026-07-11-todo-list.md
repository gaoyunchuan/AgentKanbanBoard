# To Do List Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 在现有 Agent Kanban Board 中新增一个可持久化的独立 To Do List 页面，支持树形任务编辑、状态、日期及 Markdown 命名链接扩展信息。

**Architecture:** 后端使用独立 `todo_tasks` 表保存结构化任务，前端通过一组 Tauri command 读取和保存完整任务快照。前端将树结构计算、Markdown 命名链接解析与页面组件拆开，结构操作先乐观更新，再持久化；浏览器开发环境使用固定示例数据以支持视觉验收。

**Tech Stack:** React 18、TypeScript、Tailwind CSS、Vitest、Tauri 2、Rust、rusqlite、SQLite。

## Global Constraints

- 任务状态仅包含 `todo`、`in_progress`、`cancelled`、`completed`。
- 单击状态圆圈只在 `todo` 与 `completed` 之间切换；完成时写入本地当天日期，恢复时清空实际结束日期。
- 父子任务状态完全独立，不做向上或向下联动。
- 日期字段只保存 `YYYY-MM-DD`，并在原始任务行双击后就地编辑。
- 普通 Enter 不创建任务；Cmd+Enter 新建同级任务；Tab 缩进；Shift+Tab 提升层级。
- “过程跟踪”和“结果复盘”均保存 Markdown 兼容文本，命名链接使用 `[显示名称](https://...)`。
- 不改动 Codex thread 的同步、轮询、评论懒加载链路。
