# 任务视角与本机接入修订

本轮修订来源：用户实际 Mac 验收截图。只处理本机个人工作区；不引入新的平台或迁移用户真实登录。

## 交互规则

- 主导航为会话、任务、项目、需要你、设置。需要你与设置为普通页面，不再使用设置/通知大弹窗。
- 任务视角左栏按置顶、活跃、阻塞、完成分组。打开任务、关联会话、同任务新会话、悬浮树导航都保留任务视角；全部任务树入口返回完整树。
- 左栏任务检索与中间任务树检索各自独立。树只保留任务与关联会话两列。
- 单击名称打开任务会话；单击行空白只选择任务、联动右侧详情；双击名称进入原位编辑，单击跳转短暂延迟以识别双击，不会在双击时新建 Thread。
- Escape 退出本次名称编辑；Enter 保存；Cmd+Enter 在当前任务后插入同级任务并自动聚焦；Tab 缩进到前一可见任务。同一轮编辑重复 Tab 不继续加深；Shift+Tab 可退一级。
- 状态圆圈左击完成，右击选择待办/进行中/完成/取消；运行中的状态变更先确认停止。只有根任务可置顶；移动已置顶的根到其他树时将置顶转移至新根，历史子任务置顶迁移到所属根。
- 任务行右击打开菜单，包含子任务、前置任务、属性、根置顶、删除；不再提供重命名菜单或独立省略号列。
- 任务详情常驻，初始为窗口宽度 36%，可拖动调整；默认上下文与结果合并显示，属性与设置单独页签。选择任务不会重置详情标签；上下文未保存草稿按任务隔离。
- 浏览器、文件与终端、变更属于右侧统一标签区，切换标签不卸载正在使用的工具内容。浏览器可新建、切换、关闭真实 Chrome target；最后一个标签关闭后保留新空白页。
- 项目选择统一搜索名称与路径。会话项目菜单仅显示前五个匹配项，搜索范围是全量有效项目，不是前五个项目。任务默认项目弹窗支持搜索。

## 本机正确性

原错误源于逻辑会话先创建、任务后绑定项目：显示侧继承了项目，而执行配置仍保存空工作目录。现在在首次真实执行前统一解析项目继承与目录，并验证为存在的绝对目录；无效时保留草稿，不写入待执行消息/运行。已有真实 Thread 的目录固定，不因任务默认项目改变而移动。

新增、选择项目支持 ~/ 展开及规范化，路径空白、相对目录、目录不存在分别给可处理错误。排除目录保存在 SQLite，所有项目展示/选择和新执行共用相同组件边界过滤；不使用简单字符串前缀误伤同名目录。历史任务、会话、磁盘目录不删除；已有 Thread 可以继续在原目录使用。

启动时自动尝试连接 Codex：优先检测系统/用户 Applications 中的 Desktop 内嵌可执行文件，再检测 PATH 和常见 CLI 位置。这些只是探测候选，不假定每台设备安装位置完全相同。高级路径覆盖仍保留作为自定义安装回退。

app-server 继承本机 HOME/CODEX_HOME，由 Codex 自己读取 auth.json 或系统凭据库；本应用不复制、显示或持久保存 token。账户页读取 account/read，有效账户存在就不展示重复登录要求；没有有效登录时才提供登录。Finder 启动的 PATH 通常不同于终端，本产品为子进程补充已知工具目录，不执行用户 shell 配置脚本。

## 删除旧版与兼容边界

移除旧看板入口、旧 React 页面、旧列表/关联组件与只服务旧页面的 Tauri commands；项目仍以既有数据库增量更新。保留历史表、迁移和必要 repository 兼容逻辑，不为“清理代码”删除用户业务记录。旧版 UI 测试随对应组件删除，新增测试以当前任务工作区行为为准，不将不同版本测试数量作同口径比较。

## 复验步骤

1. 启动应用：无需先输入 Codex 路径，已缓存登录应直接使用。自定义安装通过设置中的高级覆盖处理。
2. 未绑定项目创建占位聊天，随后在父任务选择项目，子任务发送消息：实际 cwd 必须是继承项目的绝对目录。
3. 两个项目检索入口分别试名称和目录；会话菜单初始与检索结果最多五项。
4. 全局树与侧栏分别搜索，验证互不筛选另一处。
5. 选择任意任务，切到属性标签，再切任务：保持属性。上下文与结果同理。
6. 双击名称编辑、Escape、Cmd+Enter、连续 Tab；验证子任务不能置顶，移动后不会保留子任务 pin。
7. 状态圆圈左击完成、右击恢复待办/进行中；活动执行先停止，旧事件不能覆盖新状态。
8. 从任务视角打开关联会话、悬浮任务树跳转、再新建同任务会话，左边始终是任务分组。
9. 打开文件终端、浏览器、Diff，切换右侧标签；浏览器开两个网页标签，关后台标签不切走当前页。
10. 设置中排除一个插件父目录：项目页、任务绑定、会话选择同步隐藏；删除规则后重新显示。已有历史保持。
