## 主要修复及验收关注

1. 创建逻辑会话后才绑定或继承项目，也会在首次实际执行前解析出有效绝对目录。目录无效时不新增执行消息或 Run，保留输入草稿。
2. 项目选择按名称和路径搜索；会话菜单最多显示五个匹配项，但检索范围覆盖全量有效项目。
3. 任务侧栏与完整树使用独立搜索状态；任务模式打开关联会话、悬浮树跳转后继续保持任务侧栏。
4. 右侧详情默认合并上下文和结果，切换任务保留详情标签与隔离草稿；工具通过右侧标签切换。
5. 圆圈完成/右键改状态、双击编辑、Escape、Cmd+Enter、Tab/Shift+Tab 及根任务置顶均有对应检查。
6. 设置与关注页为普通页面；排除项目目录规则持久化并应用于项目列表、选择器及新执行，历史不删除。
7. Codex 程序自动探测，原生进程继承 HOME/CODEX_HOME；有效账户存在时不要求再次登录。本应用不复制凭据。

## 尚未验收与保留风险

- 未登录用户真实 Codex 账号，未消耗真实模型额度；模拟协议测试不是实际模型端到端成功的证明。
- 未在用户 Mac 的 Finder 启动环境、Keychain、非常规 Desktop 安装位置验证凭据复用。
- 独立浏览器多标签实测为 Linux Chromium；用户 Mac Chrome 和站点登录需本机确认。网站验证码不属于可承诺自动通过的功能。
- 字号、行高、系统字体栈和间距已调整，但未宣称与用户 Mac 上 Codex 字体渲染像素完全一致。
- npm 安装审计仍报告现有依赖的 11 项告警（5 moderate、6 high）；本轮未运行破坏性强制依赖升级，也未据此宣称依赖安全审计通过。
- 历史数据库表和必要兼容仓储逻辑保留；删除的是旧产品入口及不可达界面代码，不删除用户数据。
