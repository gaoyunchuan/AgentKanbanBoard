## 筛选与状态图标

- 待办用虚线圆、进行中用圆内播放标记、完成用圆内勾、取消用圆内叉；阻塞另用锁，不仅依赖颜色区分。
- 状态、项目均支持多选；同一条件内部取并集，各条件之间与关键词取交集。
- 更新时间提供不限、24 小时、周视图（滚动 168 小时）、30 天。采用业务 activity_at 对外提供的 updated_at，不因读取、轮询或无变化保存而刷新。
- 筛选在同一任务节点上判断，再补齐命中节点的祖先；不会把项目匹配的父任务与状态匹配的子任务拼成虚假命中，也不会补入无关兄弟或后代。
- 支持全部展开、全部折叠和重置筛选。
- 全局树缓存关键词、状态、项目、时间范围、折叠、分页和滚动位置；侧栏搜索仍独立。缓存的是查询与视图，不冻结业务数据，返回后根据当前任务重算结果。
- 缓存格式有版本和输入校验，损坏时恢复默认。已不可用的选中项目可以从筛选器移除，避免隐形过滤。

## 开始时间

入口：任务详情 → 属性与设置 → 开始时间。

- 是可选的“最早允许自动执行时间”，不是强制定时启动，也不代替实际执行开始时间。
- 用户当地时区输入，持久化为规范 UTC 秒。旧版 date-only start_date 不迁移成自动启动条件，避免老数据意外触发任务。
- 只保存时间不隐式委托；必须委托给 Agent，且时间到达或未设置、依赖交付就绪、项目和环境可用、任务未暂停/终止、容量与目录互斥允许，才可运行。
- 等待中的任务不提前创建真实 Codex Thread。调度刷新和事务领取都检查时间，避免竞争、重复启动或通过恢复绕过门槛。
- 到点不会解除人工暂停、人工问题、环境等待、取消或完成状态。
- 当前存在有效执行时拒绝直接修改时间；先暂停并等待停止确认。保存采用预期旧值校验，不覆盖另一处的新修改。
- 清除时间后仍要点击保存；未设置则沿用已有规则。设为已过去的时间只代表时间条件已满足，不绕过其他条件。
- 时间仅作用于当前任务的自动执行，不隐式复制给其他任务；人工附加会话仍可用于提前讨论。
- 没有独立 daemon。应用关闭、电脑关机或休眠时不会执行；应用恢复后重新检查已经到达的时间，不重放结果不确定的旧执行。

自动化覆盖精确时间边界、重复领取、时间与依赖取交集、人工暂停保护、无效日期、并发编辑、旧数据迁移，以及服务级“未来时间不创建 Thread/Run → 变为到期 → 自动执行并仅产生一次运行”。服务级测试使用假 app-server 子进程，不调用真实模型。

## Codex 配置错误处理

用户截图中的 `config.toml:387:1: invalid type: integer 10, expected struct AgentRoleToml` 是配置解析失败，不能据此断言 dynamicTools 不受支持。已移除统一附加的误导性提示；只有服务端确实报告 dynamicTools 未知/不支持时才显示对应协议提示。

自动连接依次尝试现有可执行文件候选，每个候选先 initialize，再只读 config/read。不能加载当前配置的候选会结束进程并尝试下一个已安装程序。显式指定路径时尊重该路径，不静默切换。设置展示实际可执行文件和服务端报告版本。

假子进程协议测试验证了“不兼容候选 → 兼容候选”，同时确认预检没有创建 Thread/Turn，也没有写配置。失败候选的迟到断连事件不会污染之后成功的连接。

始终复用原 HOME/CODEX_HOME，不复制 token、不改写/删除/静默忽略 config.toml，也不借空配置绕过用户策略。此处只读预检验证当前有效配置；特定工作目录的项目配置仍以真实创建会话时的检查为准。

没有读取用户本机第 387 行的实际键名，也没有接入用户的真实 Codex 二进制和账户。因此不能声称其本机报错已实测消失：若所有已安装候选都无法解析该字段，需要核对实际字段、TOML 所属节与相应版本的配置结构；不能简单把数字改为字符串。

## 本机验收

正常退出旧应用，并备份 `~/.codex-kanban`；在仓库执行 `git pull --ff-only`、`make run-local`。

1. 设置中检查实际 Codex 路径和版本。连接失败应显示配置原错误，不再误报 dynamicTools；兼容候选存在时自动选择。
2. 全部任务组合选择待办/进行中、周视图及一个项目，折叠后切到聊天再返回；条件和折叠仍在，左侧搜索不受影响。重启检查查询保存。
3. 新建任务，绑定项目，先设置并保存未来开始时间，再委托给 Agent。到点前必须显示等待，不能已有真实运行；到点后仍需前置交付就绪才启动。
4. 对另一个已委托任务设置时间后主动暂停；过时仍须保持暂停。恢复时重新校验所有门槛。
5. 在同任务两个附加会话以及后台自动结果更新期间返回筛选树，检查真实更新后的结果仍符合保存条件，不冻结旧快照。
