# 聊天工作区 · 本机验收说明

## 入口与迁移

`git pull --ff-only && make run-local`。新版本默认进入聊天工作区；设置中的「旧版看板」保留原有 Desktop 导入、标签和旧 To Do 功能。不要同时用不同版本写同一个数据库。

迁移采用新增表，保留 `todo_tasks`、旧 Thread 关联、旧执行历史和结果复盘。已有托管执行自动生成主会话元数据，不在迁移期间启动模型。旧版 Desktop 导入不是本产品拥有的 Thread，不会擅自取得其执行权。

建议首次升级前正常退出旧应用并备份 `~/.codex-kanban/`；安装助手的应用备份不等于任务数据库备份。

## 交互验收

1. **普通聊天**：选择项目，发送第一条消息；任务自动生成标题，直接出现聊天而非委派表单。普通会话本轮结束不会自动完成任务。
2. **任务树**：在左侧任务入口新增根任务/子任务，编辑标题与 Markdown 上下文。点任务打开最近使用的会话；关联会话标签定位准确会话。
3. **多会话**：任务行 `+` 创建附加会话，但树节点数不变。标题下拉切换同任务会话；草稿与回复不串任务。
4. **默认项目**：子任务继承最近上级项目；会话创建时记录项目快照。修改任务默认项目不移动旧会话工作目录。
5. **依赖**：任务行 `⋯ → 设置前置任务`、`等待 N 项` 标签、右侧属性三处进入同一个选择器。只选同根树；拒绝自身、祖先和显式/隐式等待环。运行中修改要确认停止，等终止事件后应用；取消前置任务不算交付。
6. **自动主会话**：属性中委托 Codex。依赖未就绪时只有逻辑会话，不能创建真实 Thread。就绪后自动运行，带入根树、当前要求、父级上下文/结果、相关前置交付和等待的子任务结果。
7. **人工介入**：审批和问题绑定当前会话、Run、请求。关闭面板或换任务不改变请求归属。旧请求、重复回答、旧运行回调不能推进新运行。
8. **结果**：自动会话通过明确交接工具提交模型总结和证据；成功结束及验收后用于交接。附加会话点击「提取结果」会启动隔离的只读总结 Turn，不重跑业务工作。所有来源记录追加保存；相同来源范围去重；失败可单独重试；已消费的交付不能撤销来源。
9. **完成与置顶**：任务置顶 OR 会话单独置顶；不反向写任务。完成/阻塞优先于置顶。完成任务只关闭本任务会话，先停止活动执行，不级联完成子任务；重新打开只恢复主会话。
10. **删除**：有活跃执行或被外部任务依赖时不删除。其余采用软删除，历史记录保留，可从「已删除」恢复；恢复不擅自重放外部动作。
11. **侧边浏览器**：打开会话的浏览器面板，使用独立 Chrome 的实时截图、地址导航、鼠标、滚动、键盘与文字输入。Agent 的 Playwright MCP 附着同一 CDP endpoint。已有未启用工具的 Thread 可人工浏览，但 Agent 操作需新建会话；不继承个人 Chrome 登录。

## 后台分工

- `workflow.rs` 保持自动业务任务的状态权威；每个自动任务一个主会话。
- `chat_store.rs` 管理附加会话、来源明确的结果记录和字段级更新。
- `work_service.rs` 中同一调度 actor 同时控制主任务、附加会话和总结任务。最多两个执行、相同或重叠目录与人工终端互斥。
- `chat_pending_changes` 保存需停止后应用的依赖/完成变更；不能把运行中的执行仅改个标签后放行下游。
- `browser_bridge.rs` + `scripts/browser_bridge.mjs` 管理独立 Chrome。远程网页仅以画面显示，没有 Tauri IPC 桥。
- 总结只读、禁用 shell/子 Agent/MCP/联网工具。模型输出本身不证明业务验收；自动交付策略仍需用户选择。

## 版本与真实联调边界

保持 `make test`、`npm --prefix src-ui run build`、`cargo fmt --manifest-path src-tauri/Cargo.toml --check`、`git diff --check`。
新增测试验证多会话非子任务、默认项目、依赖规则、结果来源/去重、字段并发、停止与迟到消息、迁移和恢复。前端浏览器演示数据不访问真实 DB，也不会在 Tauri 调用失败时冒充真实数据。

本次构建及假子进程测试不能代替目标 Mac 的真实 Codex 登录、模型、MCP 下载、审批与沙箱联调。安装后先在临时 Git 仓库验收：一个普通聊天 → 两个会话 → 一个有依赖的子任务 → 一次人工回复 → 一次提取 → 完成/重新打开。

侧边浏览器需要 Node.js 22 与 Chrome；远程网页的原生弹窗、文件上传下载和 DevTools 尚不是完整 Chrome UI，对应工具操作与平台限制仍需单独验收。不是把任意网页塞进 iframe。

原型中的自由拖拽流程画布、海量外部回调、全自动语义返工影响分析不在本版范围。
